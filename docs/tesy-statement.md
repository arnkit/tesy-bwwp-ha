# TESY's position (customer support e-mails)

In 2026 the author asked TESY support whether the AquaThermica Pro can be connected to a smart home via Modbus or similar. Summary of the replies:

* TESY: "at the moment our HPWH range does not offer an option for offline connection, nor a way to link the interface and control logic to third-party systems." Reading the status via Modbus or a similar protocol was described as not possible.
* TESY is working on new series with a Wi-Fi control option; no details or timelines.
* On a follow-up asking about the controller's communication with its sensors: access to the controller software and the communication between controller and sensors "cannot be provided"; the appliance is designed as a standalone unit.

Consequences for this project:

* It is **not endorsed or supported by TESY**; do not contact TESY support for help with it.
* Everything here comes from passively observing the RS485 bus and comparing values with the display and the public installation manual.
* TESY may change the firmware or protocol at any time.
